# Gujarat Tailor Shop ✂️

A simple and elegant website for **Gujarat Tailor Shop** that showcases tailoring services, pricing, and an appointment booking section.

## 📌 About The Project

Gujarat Tailor Shop is a responsive website designed to present professional tailoring services in a simple and user-friendly way.

The website includes:

- Home section
- Tailoring services
- Service pricing
- Appointment booking form
- Navigation menu
- Footer section

## ✨ Features

### 🏠 Home
A hero section introducing the tailoring business with the message:

> Perfect Stitching For Every Occasion

### 🧵 Services

The website currently provides information about:

- **Suit Stitching** – Professional suit stitching for weddings, parties, and formal events.
- **Blouse Design** – Stylish blouse stitching with modern and custom designs.
- **Pant Alteration** – Fast and accurate pant fitting and alteration services.

### 💰 Pricing

| Service | Price |
|--------|------:|
| Suit Stitching | ₹2500 |
| Blouse Design | ₹800 |
| Pant Alteration | ₹300 |

### 📅 Appointment Booking

Customers can enter:

- Name
- Mobile Number
- Preferred Date

and submit the appointment form.
